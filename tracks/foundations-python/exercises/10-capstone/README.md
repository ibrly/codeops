# 10 · Capstone: write it yourself

**This is the Foundations capstone.** There's no planted bug. The function is empty, and you write it from scratch using what you've practiced: loops, conditionals, dictionaries, and edge cases. Your tutor will mostly ask you questions to help you think it through. If you ask for help, it can point you to where to look or give a small nudge, but it won't show you any code or the answer. Any hint records the capstone as *assisted*. That's fine: you can reset it with a fresh copy and finish it on your own another day, which counts as completing it.

**Goal.** `longest_song(playlist)` should give back the song dictionary with the most `"seconds"`. If two songs tie, give back the first one. For an empty playlist, give back `None`.

**Run the test:**

```bash
python3 -m unittest
```

**Done when** all the tests pass without any hints. Then you've completed Programming Foundations.
