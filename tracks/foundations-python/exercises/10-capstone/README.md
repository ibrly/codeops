# 10 · Capstone: write it yourself

**This is the Foundations capstone.** There's no planted bug. The function is empty, and you write it from scratch using what you've practiced: loops, conditionals, dictionaries, and edge cases. Your tutor can ask questions, point you to where to look, and give small hints, but won't give partial or full solutions. That's what makes finishing it mean something.

**Goal.** `longest_song(playlist)` should give back the song dictionary with the most `"seconds"`. If two songs tie, give back the first one. For an empty playlist, give back `None`.

**Run the test:**

```bash
python3 -m unittest
```

**Done when** all the tests pass without the escape hatch. Then you've completed Programming Foundations.
