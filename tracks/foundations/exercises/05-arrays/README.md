# 05 · Arrays

**Concept.** Arrays have methods that loop for you. `forEach` runs a function on every item and gives back nothing; it's for *doing* something with each item. `map` runs a function on every item and gives back a *new array* made of whatever that function returns; it's for *turning* a list into another list.

**Goal.** `songTitles(playlist)` should give back an array of just the titles, like `["Intro", "Outro"]`.
