# 10 · Capstone: write it yourself

**This is the Foundations capstone.** There's no planted bug. The function is empty, and you write it from scratch using what you've practiced: loops, conditionals, objects, and edge cases. Your tutor will ask you questions to help you think it through, but won't point at the problem, give hints, or show code. If you do take a hint, that's fine: the capstone is recorded as *assisted*, and you can come back another day, reset it with a fresh copy, and finish it on your own. Finishing it unaided is what makes it mean something.

**Goal.** `longestSong(playlist)` should give back the song object with the most `seconds`. If two songs tie, give back the first one. For an empty playlist, give back `null`.

**Run the test:**

```bash
node --test
```

**Done when** all the tests pass without any hints. Then you've completed Programming Foundations.
