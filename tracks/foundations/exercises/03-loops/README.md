# 03 · Loops

**Concept.** A `for` loop has three parts: where to start (`let i = 0`), when to keep going (`i < something`), and how to step (`i++`). Arrays start counting at index `0`, so an array with 3 items has indexes `0`, `1`, and `2`. Getting the "keep going" condition one step wrong is so common that it has a name: an *off-by-one* error.

**Goal.** `totalDuration(songs)` should add up the `seconds` of every song in the playlist.
