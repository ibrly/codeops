# 04 · Functions

**Concept.** A function can *show* a value or *give it back*. `console.log(x)` prints `x` to the screen for a human to read, but the code that called the function gets nothing. `return x` hands `x` back to the caller so the program can keep using it. A function with no `return` gives back `undefined`.

**Goal.** `formatDuration(185)` should give back the text `"3:05"`, so the playlist can display it next to each song.
